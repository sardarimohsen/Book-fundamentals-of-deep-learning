## 📖 About the Book

**Fundamentals of Deep Learning** takes readers from the mathematical and machine learning groundwork all the way to modern deep architectures with a strong emphasis on **learning by doing**. Every practical chapter in the book is paired with runnable code in this repository, so you can experiment as you read.

## ⚡ Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/sardarimohsen/Book-fundamentals-of-deep-learning.git
cd Book-fundamentals-of-deep-learning

# 2. Install dependencies
pip install -r code/requirements.txt

# 3. Launch a chapter notebook
python code/Chapter 7 - Introduction to TensorFlow and Keras/Chapter_07_tensorflow_keras.py
```
